Uygulama

GitHub bağlantısı

Telefondan yazar ekleyip çıkarabilmen için uygulamanın GitHub'daki listene yazabilmesi gerekiyor. Bunu bir kez ayarlaman yeterli.

Anahtar nasıl alınır?
  1. Telefonda github.com'a giriş yap, sağ üstteki profil resmine dokun → Settings.
  2. En altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Ad: Takip uygulaması. Süre: en uzununu seç.
  4. Repository access → Only select repositories → takip deposunu seç.
  5. Permissions → Repository permissions bölümünde Contents: Read and write seç. "Şimdi kontrol et" düğmesi için Actions: Read and write da seçebilirsin.
  6. Generate token'a bas, çıkan github_pat_… yazısını kopyalayıp yukarıya yapıştır.
